# Methodology

How every number in Dati di Lugano was found, extracted and checked, and the decisions and corrections made while building it (14–15 October 2026).

Companion files:
- [`sources/`](sources/README.md): the exact documents used, with original URL, retrieval time and SHA-256.
- [`TRACE.md`](TRACE.md): every figure extracted from the city's PDFs, with page, printed text and confidence (generated by `npm run provenance`).

## 2. How the extraction works

**Canton spreadsheets** (`src/annex.ts`). Sheets are found by title text, the municipality row by name (case and the `[*]` water-accounts marker ignored), columns by their header text, never by position. Amounts are CHF thousands; ratios are fractions.

**City PDFs** (`src/figures.ts`, TypeSafe "pre-parsed value extraction", model `jev-1.14.0`):
1. Code finds every amount in the PDF text (exact francs such as `473’565’042.50`, and rounded amounts followed by "Mio" or "milioni"), with its table row (`rowLabel`), its position in the row (1 = actual, 2 = budget, 3 = difference) and the surrounding lines.
2. Jev answers one Choice question per figure, choosing a candidate id or `none`. It never writes a number.
3. Code copies the chosen number unchanged. Probability is pooled across repeat printings of the same value (within the printed precision). A figure is **accepted** at a pooled probability of at least 0.8, otherwise **review**.

Deficits printed as positive amounts ("disavanzo … CHF 4.2 milioni") are stored as negative. Responses are cached (`data/cache/typesafe.json`, not committed) by a hash of the exact request.

**News watcher** (`src/watch.ts`): new documents on the finance page are flagged by code; new press releases are classified by Jev (one Choice per release, with the first 1’500 characters as evidence) and flagged when P(budget, accounts, rating, borrowing or assets) ≥ 0.5.

### Budget vs actual (`npm run budget`)

The city's final-accounts decks print each recap row as *actual · budget · difference · percent*. `src/budget.ts` reads the budget column directly from that table (row label and column position, no model involved) for 9 rows in 2024 and 2025: operating spending and revenue, operating balance, total operating result, gross investment, investment receipts, net investment, self-financing and the overall financing result. Checks that stop the run: actual − budget equals the printed difference to the cent (18 of 18 rows), and every actual already extracted in `out/city-figures.json` matches (10 of 10). The 2025 self-financing budget of CHF 35'747 is as printed; it agrees with the deck's summary ("P2025 0.0 Mio") and the 2026 budget release ("contro CHF 0.0 milioni nel preventivo 2025").

### School figures (`npm run schools`)

`src/schools.ts` extracts seven figures per school year from the City's school-start releases (2 September 2024, 3 September 2025, 31 August 2026): total pupils, kindergarten pupils, sections and average, primary pupils, classes and average. It uses the same TypeSafe pre-parsed value extraction as the financial figures: code lists every number in the release with its surrounding words (35–40 per release), Jev picks one per figure, and code copies the printed value. Each year must pass three arithmetic checks: kindergarten + primary = total, and sections × average = pupils within the rounding of the printed average. Run of 15 October 2026: 21 of 21 figures accepted (confidence 0.96–0.99), 9 of 9 checks passed, all values equal to a manual phrase check of the PDFs.

## 5. Decisions and corrections

In the order they happened.

1. **First answer, EFV data.** Initially described as possibly containing per-municipality data; on checking, the federal statistics aggregate municipalities per canton. Recorded as such.
2. **Annex parsing.** Sheet numbers shift between years (indicators are `tab13` in 2023, `tab12` in 2024), so sheets are found by title. Two parser bugs were fixed: the 2023 mean row "MEDIA DEI COMUNI" was being ranked as a municipality, and the 2023 debt header reads "(1'000 franchi)" instead of "(1'000 fr.)".
3. **2023 self-financing 501.6%.** The value is in the canton's file; it reflects one-off investment receipts. Flagged automatically, rated "distorted" and given no rank.
4. **Ranking only where direction is clear.** Absolute debt and investment share are not ranked, because a higher or lower value is not better.
5. **Extraction: first run.** 4 of 5 checks matched; the 2024 total result was mis-picked (the budget difference, +7.0M) with low confidence and correctly held for review.
6. **Extraction: repeat printings.** Probability split between equivalent candidates (a table value and its rounded summary), so correct answers fell below the threshold. Fixed by pooling probability per value.
7. **Extraction: row structure.** The 2024 deck prints each value on its own line. Candidates now carry the row label and their position in the row. After this, 5 of 5 matched.
8. **Budget plan wording.** The first question for "debt after the 2026 investments" returned the plan peak (1’356.3M) at 0.70, held for review. The question was reworded to follow the sentence's structure; the answer became 1’233.2M.
9. **Bond register.** Matured bonds were initially missing, undercounting end-2024. The four matured issues were added. Issues not listed on SIX were classified as private placements to reconcile with the city's public total (RSI).
10. **Moody's debt ratios.** First taken from a search-engine summary and attributed to the city's release. The release does not contain them. The figures were traced to Corriere del Ticino (22 April 2026) quoting Moody's April 2026 review, and re-attributed; the 2025 value is Moody's forecast.
11. **SIX prices removed.** Prices and yields were collected during research from the SIX website's data feed. SIX market data is licensed, so the public version keeps only bond terms and links to SIX. Earlier repository history containing prices was not carried over.
12. **Publishing.** The project first lived on a private branch of another repository; it was moved to this public repository with fresh history and a GitHub no-reply author address.
13. **Population base (checked 15 October 2026).** Per-resident figures use Lugano's **63’629** permanent residents at 31.12.2024 (federal STATPOP definition). Three sources agree: USTAT `T_010202_020.xlsx` (row "5192 Lugano"), the canton's population list for equalisation ([FU_pop2024.pdf](https://www4.ti.ch/fileadmin/DI/DI_DI/SEL/Comuni/Perequazione/FU_pop2024.pdf)) and the canton's indicators table (655’536.7 thousand net debt ÷ 10’302.48 per resident = 63’629). The City's statistics office publishes higher counts for the same date ([release of 16 January 2025](https://www.lugano.ch/news/20250116-dati-statistici-2024/)): 64’430 permanent residents in its own register, and 68’507 in total once 2’774 secondary residents and 1’303 short-stay residents and cross-border workers living in Lugano are added. Those counts are not used, because the canton computes every municipality on the federal definition and a different base for Lugano alone would break the Ticino comparison (using 64’430 would lower Lugano's per-resident figures by about 1.2%). Per-resident is not per taxpayer: children are residents who do not file, and people who own property in Lugano but live elsewhere can pay tax there.

## 6. Known limitations

- The canton publishes about 14 months after year end; 2025 and later come only from the city's PDFs and plans.
- Years before 2023 use the old accounting model (MCA1) and are not parsed.
- Plan figures exist only for 2026, 2030 and 2033 in the press release; the dashboard draws straight lines between them.
- Bond volumes are issue volumes; partial buybacks, if any, are not reflected.
- `TRACE.md` locates each value by the first page containing it; for values printed on several pages it prefers the page that also contains the value's line.

## 7. Reproducing

```
npm install
npm run map                           # canton spreadsheets, source catalog, bond register
TYPESAFE_API_KEY=... npm run figures  # city PDFs (needs your own TypeSafe key)
npm run debt                          # debt profile
npm run provenance                    # archive sources/ and write TRACE.md
```
